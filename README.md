# Art portfolio project

This is project for my personal art portfolio.


## Installing Dependencies

- `dioxus-cli`

### Windows, Linux

```bash
cargo install --git https://github.com/DioxusLabs/dioxus dioxus-cli --locked
```

### NixOS

```bash
nix develop
```

## Building

```bash
dx serve
```

## Publishing

```bash
dx bundle --web --ssg
```
```bash
dx build --release
```
